# MyBatis Generator 插件拆分说明

## 概述

原始的 `VoGeneratorPlugin` 插件已被拆分为两个独立的插件，以提供更好的模块化和灵活性：

1. **VoRecordGeneratorPlugin** - 专门生成 VO 记录类
2. **ConverterGeneratorPlugin** - 专门生成 MapStruct 转换器接口

## 插件详情

### 1. VoRecordGeneratorPlugin

**功能：** 生成 Java 14+ 记录类作为值对象（VO）

**特性：**
- 生成不可变的 VO 记录类，命名格式为 `DomainNameVo`
- 可配置的包结构
- 支持所有域模型字段类型
- 自动导入管理
- 使用数据库列注释生成 Swagger3 字段描述
- LocalDateTime 字段自动添加 JSON 和 DateTime 格式注解

**配置属性：**
- `voPackage` - VO 类的目标包（默认：model.vo）
- `voTargetProject` - VO 类的目标项目路径（默认：src/main/java）

**使用示例：**

```xml

<plugin type="cloud.catfish.mbg.plugin.VoRecordPlugin">
    <property name="voPackage" value="cloud.catfish.mbg.model.vo"/>
    <property name="voTargetProject" value="src/main/java"/>
</plugin>
```

### 2. ConverterGeneratorPlugin

**功能：** 生成 MapStruct 转换器接口

**特性：**
- 创建双向转换的 MapStruct 转换器接口
- 可配置的包结构
- 支持 Spring 组件模型集成
- 生成全面的转换方法（单对象和列表转换）
- 为所有生成的方法提供完整文档

**配置属性：**
- `converterPackage` - 转换器类的目标包（默认：model.converter）
- `converterTargetProject` - 转换器的目标项目路径（默认：src/main/java）
- `voPackage` - VO 类所在的包（默认：model.vo）
- `componentModel` - MapStruct 组件模型（默认：spring）

**使用示例：**

```xml

<plugin type="cloud.catfish.mbg.plugin.MapstructConverterPlugin">
    <property name="converterPackage" value="cloud.catfish.mbg.converter"/>
    <property name="converterTargetProject" value="src/main/java"/>
    <property name="voPackage" value="cloud.catfish.mbg.model.vo"/>
    <property name="componentModel" value="spring"/>
</plugin>
```

## 迁移指南

### 从原始 VoGeneratorPlugin 迁移

**原始配置：**
```xml
<plugin type="cloud.catfish.mbg.plugin.VoGeneratorPlugin">
    <property name="voPackage" value="cloud.catfish.mbg.model.vo"/>
    <property name="mapperPackage" value="cloud.catfish.mbg.mapper.vo"/>
    <property name="voTargetProject" value="src/main/java"/>
    <property name="mapperTargetProject" value="src/main/java"/>
</plugin>
```

**新配置（两个独立插件）：**

```xml
<!-- VO 记录类生成插件 -->
<plugin type="cloud.catfish.mbg.plugin.VoRecordPlugin">
    <property name="voPackage" value="cloud.catfish.mbg.model.vo"/>
    <property name="voTargetProject" value="src/main/java"/>
</plugin>

        <!-- MapStruct 转换器生成插件 -->
<plugin type="cloud.catfish.mbg.plugin.MapstructConverterPlugin">
<property name="converterPackage" value="cloud.catfish.mbg.converter"/>
<property name="converterTargetProject" value="src/main/java"/>
<property name="voPackage" value="cloud.catfish.mbg.model.vo"/>
<property name="componentModel" value="spring"/>
</plugin>
```

## 优势

### 1. 模块化
- 每个插件专注于单一职责
- 可以独立使用任一插件
- 更容易维护和扩展

### 2. 灵活性
- 可以选择只生成 VO 类而不生成转换器
- 可以选择只生成转换器而使用现有的 VO 类
- 独立配置每个插件的参数

### 3. 可维护性
- 代码结构更清晰
- 更容易进行单元测试
- 更容易添加新功能

## 生成的代码示例

### VO 记录类示例
```java
@Schema(description = "User VO")
public record UserVo(
    @Schema(description = "Primary key identifier")
    Long id,
    @Schema(description = "User login name")
    String username,
    @Schema(description = "User email address")
    String email,
    @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss", timezone = "GMT+8")
    @DateTimeFormat(pattern = "yyyy-MM-dd HH:mm:ss")
    @Schema(description = "Record creation timestamp")
    LocalDateTime createTime
) {}
```

### 转换器接口示例
```java
@Mapper(componentModel = "spring")
public interface UserConverter {
    UserVo toVo(User user);
    User toDomain(UserVo userVo);
    List<UserVo> toVoList(List<User> users);
    List<User> toDomainList(List<UserVo> userVos);
}
```

## 注意事项

1. **Java 版本要求：** VoRecordGeneratorPlugin 需要 Java 14+ 支持记录类
2. **依赖关系：** ConverterGeneratorPlugin 需要 MapStruct 依赖
3. **包配置：** 确保两个插件的 `voPackage` 配置一致
4. **执行顺序：** 建议先配置 VoRecordGeneratorPlugin，再配置 ConverterGeneratorPlugin

## 总结

通过将原始插件拆分为两个独立的插件，我们实现了：
- 更好的关注点分离
- 更高的灵活性和可配置性
- 更容易的维护和扩展
- 更清晰的代码结构

用户现在可以根据具体需求选择使用一个或两个插件，提供了更大的使用灵活性。
